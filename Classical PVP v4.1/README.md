# 古典作曲家 大乱斗 · CLASSIC COMPOSERS BATTLE

**Version 4.1**（标题画面右下角显示版本号）

一款单机运行的**古典作曲家格斗对战游戏**。**50 位作曲家**、3V3 轮换赛制、
**三类羁绊共鸣**（时期 / 地区 / 体系）、**五套战斗体系**（和声 / 领域 / 乐章 / 回旋 / 卡农）、
**24 首** 8bit 芯片音乐 BGM，美术风格模仿 90 年代红白机（FC）像素格斗游戏。

## 更新日志

### v4.1（本次）
* **修复敌方 AI 从不出普攻的严重问题**：AI 决定出拳/踢腿后，同一个 `update()` 里紧接着的
  移动代码会执行 `setAnim('idle'/'walk')`，把刚设置的动作覆盖掉，于是攻击动画（与判定帧）
  永远不出现 —— 这就是 AI“只会放技能、毫无近身威胁”的根因。现在出招后的那一帧不再碰动作
  （技能因为是瞬发效果所以一直正常，只有依赖动画判定的普攻被吃掉）。
  实测 50 位角色平均 **26 次普攻 / 15 秒**（约 13 次真正命中、合计约 195 点伤害），此前为 **0**。
* **调整 AI 攻击优先级**：贴身时普攻优先于技能（技能就绪时 55~75% 出普攻，全部冷却时 92%），
  技能不再无脑压过拳脚；补上此前从未被赋值过的 `attackCd` / `jumpCd` 计时器
  （原先只有递减、没有赋值，等于死代码），出招节奏不再失控，也不会原地连点。
* **AI 不再开局空放终极技**：
  * 新增**实际交战计时** `playT`（不含 106 帧开场倒计时），本回合交战前 **1.7 秒**不放大招。
    此前用全局 `t` 判断，保护期几乎被开场演出吃光，AI 刚能行动就交大招；
  * 按终极技类型区分有效距离：全屏 9999 / 领域 320（自我强化 230）/ 回声 330 /
    乐章 250 / 卡农 230 / 投射 340 / 判定框 `宽 ×0.85`；
  * **治疗、护盾、增益、自我强化类**必须等对手进入 230px 才放，避免持续时间在空场里耗尽。
    12 位「和声」体系角色中有 6 位的终极技属于这一类，此前必然开局白放；
  * 对手处于无敌帧（黄色羁绊免疫 / 技能无敌）时不浪费伤害型大招；自己残血时更愿意搏一把。
  实测 50 位角色共 50 次大招释放，**没有一次落在打不到的距离**。
* **新增 12 首 BGM（共 24 首，随机播放）**：
  J.S.巴赫《d 小调托卡塔与赋格》、维瓦尔第《四季「春」》、亨德尔《水上音乐·角笛舞曲》、
  J.海顿《惊愕交响曲》、舒伯特《鳟鱼》、肖邦《幻想即兴曲》、威尔第《饮酒歌》、
  格里格《在山魔王的宫殿里》、柴可夫斯基《胡桃夹子·特列帕克》、
  德沃夏克《自新大陆·念故乡》、德彪西《月光》、格什温《蓝色狂想曲》；
  并新增 6 种鼓型（toccata / gallop / swing / lullaby / ballet / procession）。
* **优化原有 12 首 BGM**：
  * 新增**第三声部（和弦 / 分解和弦层）**，24 首全部配上和声，声场明显变厚
    （短和弦按自身长度循环，不会“放一遍就消失”）；
  * **修复低音与和弦“放到一半就消失”**：此前所有曲目的贝斯都比旋律短
    （例如《芬兰颂》贝斯只有 48/124 个单位，循环后 60% 的时间没有低音），
    现在和声声部按自身长度循环，贯穿整个循环；
  * **循环长度取各声部最长值**（原先只按旋律长度回绕，会截断较长的贝斯 / 和弦）；
  * 旋律加入**音量人性化**（每次触发 ±9% 随机增益），重复循环不再机械；
  * 爵士曲支持 **swing 摇摆**（《蓝色狂想曲》后半拍推后 18%），《月光》使用慢速琶音 strum。

## 运行方式

**双击 `开始游戏.html`** 即可（纯前端，无需安装任何东西、无需联网、无外部素材）。
推荐浏览器：Edge / Chrome / Firefox（需支持 Web Audio API）。

> 首次按键后音乐才会响起——这是浏览器的自动播放限制，正常现象。

| 功能 | 按键 |

| 踢腿 | `D` |

菜单中：标题画面 `Enter`/`Space` 开始；选人界面 `IJKL` 移动光标，

`P` 返回标题画面，`O` 打开设置，`Enter` 开战。战斗中以 `R` 返回选人界面。

**玩家永远操控左侧角色**，右侧由 AI 算法控制。角色永远自动面向对手。

### 格挡规则（按住 `S`）

* 按住期间角色保持**专门的戒备动画**（双臂交叉护住身前 + 蓝色光罩脉动），被击中时播放
  “被震退再撑回来”的受击帧。即使被打进硬直，只要还按着格挡键，格挡姿态就持续保持。
* **普通攻击**：**75% 概率完全免疫**（0 伤害、无硬直），另外 25% 照常吃满伤害。
* **技能伤害**：**60% 概率随机减免原本伤害的 20%~40%**，另外 40% 无减免。
* 无论概率结果如何，格挡都会把击退降到 60%、硬直减半。
* 标注“无视格挡”的技能（穿透 / 全屏类终极技）不受以上规则影响。

## 赛制规则

1. 开局先**选择三名出场作曲家**（用 `IJKL` 移动光标，`A`/`D` 选中或取消，`P` 清空）。
   敌方三名由系统随机匹配（不重复）。
2. 双方按顺序各上一名角色对战。
3. 一方角色战败 → 该方换上下一名，**战胜方继续留在场上，并保留本轮结束时的血量**。
4. 某一方三名角色全部战败即分胜负，**每局最多 5 轮**。
5. 每轮限时 60 秒；超时后按剩余血量百分比判定该轮胜负。

## 羁绊共鸣

每位作曲家带有**三种标签**，选出的三人中同一标签达到 **2 人及以上**即触发共鸣，
**效果只作用于参与共鸣的角色**（未参与的角色不享受）。三种共鸣可以同时拥有。

| 标签类型 | 颜色 | 共鸣效果 |
| --- | --- | --- |
| 时期划分 | 🟩 绿色 | 参与角色造成的伤害 **+12%** |
| 地区派别 | 🟨 黄色 | 参与角色**每 12 秒免疫全部伤害 2.5 秒** |
| 战斗体系 | 🟥 红色 | 依子标签各不相同（见下表） |

选人界面实时显示三种共鸣预览与生效角色；对战中双方血条下方显示三色共鸣徽标，
黄色共鸣还会显示下一次免疫的倒计时与“免疫中”状态。敌方随机阵容同样适用羁绊（保证公平）。

**红色体系子标签（v4.0）**

| 子标签 | 效果 |
| --- | --- |
| 和声 | 生命值上限 +18% |
| 领域 | 移动速度 +20% |
| 乐章 | 伤害有 20% 概率翻倍 |
| 回旋 | 免疫 8% 受到的伤害 |

> 另一处补入说明：**武满彻**在需求里未归入任何新体系分组，因其与陈其钢、布里顿同属现代乐派，
> 已编入「乐章」体系。

## 五套战斗体系

> 红色「体系」羁绊标签正是按这里的五套机制划分的（和声 / 领域 / 乐章 / 回旋 / 卡农），
> 详见上文「羁绊共鸣」。

**v2.0 的两套**（原有 25 位角色的技能机制自 v2.0 起未再改动，v2.1 仅下调了领域伤害）：

### 一、领域（Field）

在战场上留下**持续数秒的音之领域**，是站位与走位层面的压制手段。

* 领域按半径覆盖地面，画面上表现为带旋转符文、上升光柱与脉冲边界的魔法阵；
* 类型包括：**持续伤害**、**减速**、**治疗自身**、**护甲减伤**、**吸血**，以及拉威尔专属的**渐强**；
* 分为**跟随施法者**与**落在对手脚下**两种投放方式；同一施法者的同类领域只保留最新一个；
* **领域伤害在 v2.1 统一下调 20%**（`FIELD_DAMAGE_SCALE`），减速也没有 0.5 的下限，
  保证被压制的一方仍有机会脱身或反击；
* AI 会主动走出对手的**伤害型**领域——但逃太久它会回身硬拼，不会无限风筝。

### 二、回声（Echo）

召出**作曲家的半透明虚影**（残影会真实挥拳／踢腿），从不同方位与不同时刻发动攻击。

* 虚影按指定方位（对手身前／身后／两侧）与延迟依次现身，脚下有魔法阵；
* 出生与命中都有专门的粒子表现；虚影攻击遵循技能的全部判定与格挡规则；
* 因为落点是“对手的当前位置”，走位可以躲开，但背后突袭极难反应——
  例如海顿「惊愕交响曲」就是**从对手背后突然现身的一记重击**。

**v3.0 新增的三套**（25 位新角色）：

### 三、乐章（Movement）

技能展开一段**多段式乐句**，按拍点**自动连续发动不同招式**（每段的伤害、范围、硬直各不相同）。

* 施法者头顶会浮出**五线谱指示器**，用音符点标出还有几拍未奏；
* **连奏期间施法者不被招式动画锁定**（`freeMove`），仍可自由走位、跳跃、格挡甚至另起一招——
  这是与“多段连击”最本质的区别；
* 每到一个拍点都会自动判定命中，玩家只需专注走位；
* 代表技能：柴可夫斯基「天鹅湖·四小天鹅之舞」（四段踢击）、
  格里格「在山魔王的宫殿里」（四段伤害逐段攀升）、
  斯特拉文斯基「春之祭」（间隔忽长忽短的四段重音）、
  伯恩斯坦「坎迪德序曲」（四段急板）等。

### 四、回旋（Rondo）

放出的乐句**飞到尽头会折返**，去程与回程**各判定一次**。

* 回程的伤害通常**高于去程**（面板上 `damage` / `backDamage` 分开标注）；
* **回程命中会把对手向施法者方向拖拽**（`pull`），可以把逃跑的对手硬拽回来；
* 乐句回到施法者手中后消失，飞行途中带方向指示与尾迹特效；
* 代表技能：柏辽兹「幻想交响曲·固定乐思」（那条挥之不去的旋律）、
  乔普林「枫叶拉格」（切分的乐句弹出去又跳回来）、
  H.普赛尔「狄多与埃涅阿斯·狄多的哀歌」等。

### 五、卡农（Canon）

开启后的一段时间内，自己的**每一次命中都会被一个延后的“模仿声部”重奏一次**。

* 重奏伤害 =（该次命中伤害 × 面板比例），在设定的延迟帧后自动结算；
* 重奏时对手身上会浮现**虚影挥击 + 音符爆散**，自身头顶有音符环与剩余时间读数；
* 卡农是**自我强化**：持续期间打得越密，追加伤害越多；
  适合先手开启、再以多段技能或乐章扩大收益；
* 代表技能：帕格尼尼「二十四首随想曲」（比例 0.6）、
  布列兹「应答曲」（0.85，最高倍率）、
  韦伯「魔弹射手·魔弹」（同一颗子弹再打一次）、
  马肖「等节奏经文歌」（严格重复）等。

## 五十位作曲家

每人拥有两个技能（`Q` / `W`）与一个终极技能（`E`），技能名称取自其代表作品，效果“望文生义”地对应曲目意境。

**冷却时间按技能机制自适应（v4.0）**：

* **持续型技能**（领域 / 回声 / 乐章 / 回旋 / 卡农 / 护盾 / 增益 / 状态）：
  冷却 = 持续时间 + 余量（普通技能 +2.5 秒，终极技 +5 秒）。
  例如拉威尔「波莱罗舞曲」持续 12 秒 → 冷却 15 秒；8 秒的领域 → 冷却 11 秒。
* **纯伤害型技能**（投射物 / 突进 / 连击 / 无持续时间的终极技）：
  冷却相应放低，普通技能 4 秒、终极技 12 秒。
* 全部 150 个技能都满足「冷却 > 持续时间」，不存在效果无限延续的情况。

## BGM

对局中随机播放一位作曲家作品的 **8bit 芯片音乐改编版**，共 12 首循环曲目：

命运交响曲、土耳其进行曲、匈牙利舞曲第五号、马勒第五交响曲小柔板、女武神的骑行、
梦幻曲、拉赫玛尼诺夫第二钢琴协奏曲、第二圆舞曲、升华之夜、芬兰颂、
斯克里亚宾练习曲作品 8 之 12、李斯特《钟》。

音乐由 Web Audio API 实时合成方波 / 三角波 / 噪声（旋律 + 贝斯 + 鼓组），
不使用任何音频文件。每轮开始时随机切换曲目。

## 技术实现

```
开始游戏.html        页面与按键说明（双击这个文件启动）
styles.css          街机外壳样式
js/audio.js         8bit 音乐引擎（24 首曲谱 + 3 声部 + 20 种音效 + 15 种鼓型）
js/characters.js    50 位作曲家的数值、配色、技能与羁绊标签
js/sprites.js       像素角色绘制（骨骼式姿势 + 低帧率关键帧动画）
js/effects.js       像素字体（含小写字母 + 中文自动回退）+ 技能特效粒子系统
js/ai.js            敌方 AI（距离/冷却/性格驱动；会躲伤害领域但不会无限风筝）
js/game.js          对战引擎（五套战斗体系、羁绊、轮换赛制、界面）
js/main.js          固定 60Hz 逻辑主循环
tools/              开发期验证工具（不影响游戏运行）
```

* 逻辑固定 60Hz 步进；**动画每 6~8 帧才切一次关键帧**，还原红白机特有的“卡顿感”。
* 角色为“骨骼式”绘制：大腿/小腿/上臂/前臂的角度数据驱动，因此挥拳、踢腿、
  格挡、格挡受击、**领域施法、回声召唤、乐章挥棒、回旋甩出、卡农倾听**、
  跳跃、受击、胜利姿势都是独立编排的动画。
* **形象差异由三层数据叠加而成**（v3.1）：
  1. **发型库**（`HAIR_STYLES`，20 种，前后两层圆角矩形数据驱动）；
  2. **面部特征**（`FACE_MAP`：脸型／眼型／眉型／鼻型／嘴型／腮部阴影）；
  3. **衣着与配饰**（燕尾服／长袍／修女服三套版型 + 眼镜／单片眼镜／烟斗／耳饰／络腮胡）。
  三者组合后 50 位作曲家**形象两两不同**，`tools/facesheet.html` 可放大逐一核对。
* 像素风判定：所有角色、特效、文字均用整数像素矩形/圆角矩形绘制，
  `image-rendering: pixelated` 保证放大后仍是硬朗色块。
