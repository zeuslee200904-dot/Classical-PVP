# 古典作曲家 大乱斗 · CLASSIC COMPOSERS BATTLE

**Version 6.0**（标题画面右下角显示版本号）

一款单机运行的**古典作曲家格斗对战游戏**。**100 位作曲家**、3V3 轮换赛制、
**三类羁绊共鸣**（时期 / 地区 / 体系）、**十套战斗体系**（和声 / 领域 / 乐章 / 回旋 / 卡农 / 循环 / 节拍 / 华彩 / 终曲 / 顽固）、
**32 首** 8bit 芯片音乐 BGM，美术风格模仿 90 年代红白机（FC）像素格斗游戏。

#### 三、三套新体系（红色标签）

| 标签 | 共鸣效果 | 实现位置 |
| --- | --- | --- |
| 🟥 **华彩** | 每 **8 秒**，命中敌人时使其**眩晕 0.7 秒**（期间无法操作） | `Fighter.cadenzaTimer` → `stepFighter` 回充 → `hitTarget` 消耗 |
| 🟥 **终曲** | 命中后若敌人生命降至**其上限的 5%** 以下，**立即斩杀并结束本轮** | `Game.prototype.tryExecute`（`hitTarget` 与 `fieldDamage` 都会调用） |
| 🟥 **顽固** | **抗打断**：普通攻击造成的硬直 **60% 概率完全无效**；控制类效果**影响时间 −50%** | `Game.prototype.controlFrames` + `hitTarget` 里的 `negateControl` |

设计上的几条明确取舍（都写进了代码注释）：

* **华彩的充能只在"真正打中并造成伤害"时消耗**——被格挡完全免疫、或被回旋反弹护盾吃掉的那一次
  命中不会白白浪费充能。
* **华彩的眩晕沿用作弊硬直（stun）在本作里既有的语义**：不能出招 / 不能移动 / 不能放技能，
  但**按住 S 的格挡姿态仍然保持**（`readPlayerInput` 里原本就写着"硬直期间不能出新招，但格挡仍在"）。
  需求原文说"不可进行任何操作"，这里按本作既有规则统一，没有为它单开一套例外。
* **终曲的 5% 门槛按"受击方自身的生命上限"判定**。需求原文的"自身"也可以读成攻击方，
  但全员生命上限都在 271~346 之间，两种读法最多相差 3 点，因此采用标准斩杀语义。
  另外：血量被打到 0 的那一击仍走正常 KO 流程（不会重复演出）。
* **顽固的两条效果互斥**：普通攻击走"60% 完全无效"（没被无效的那 40% 照常吃满硬直）；
  其余控制类效果（技能自带硬直、眩晕 / 定身状态、以及华彩的眩晕）走"时间 −50%"。
  需求给的例子正好对上：**0.7 秒 → 0.35 秒（42 帧 → 21 帧）**。
  「控制类效果」在本作里指**使角色无法操作**的效果，也就是 `stun` / `root`；
  减速与强制起舞不禁止操作，因此不吃这一条。

| 标签 | 旧值 | v6.0 |
| --- | --- | --- |
| 🟥 回旋 | 免疫 8% 伤害；每 7 秒 **33%** 概率展开 **0.8 秒**反弹护盾，反弹 **50%** | 免疫 8% 伤害；每 7 秒 **75%** 概率展开 **1 秒**反弹护盾，反弹 **60%** |

#### 五、新增绿 / 黄标签，以及**跨组共鸣**

新角色按需求编入原有的绿（时期）/ 黄（地区）体系，并为此新增两个地区标签：

| 新增地区 | 使用者 | 共鸣规则 |
| --- | --- | --- |
| 南欧 | 萨拉萨蒂 | 可与**北欧、东欧**共鸣 |
| 东欧 | 埃内斯库 | 可与**北欧、南欧**共鸣 |

`REGION_GROUPS` 里因此多了一个三标签集合 `['北欧','南欧','东欧']`。
注意"能共鸣"在本作里**不是等价关系**（法派同时与波兰、比利时共鸣，而波兰与比利时彼此无关），
所以仍然是"显式列出所有能一起共鸣的标签集合、逐集合数人头"的写法：

```
萨拉萨蒂 + 尼尔森   → 黄·北欧/南欧 ×2  ✅
埃内斯库 + 阿特伯格 → 黄·北欧/东欧 ×2  ✅
萨拉萨蒂 + 埃内斯库 → 黄·南欧/东欧 ×2  ✅
萨拉萨蒂 + 肖邦     → 黄·无            ✅（南欧不与波兰共鸣）
萨拉萨蒂 + 伊萨伊   → 黄·无            ✅（南欧不与时利时共鸣）
```

#### 六、平衡自查与收敛（这是本轮花时间最多的一项）

用 `tools/balance-test.mjs`（AI 对战，100 人 × 12 位固定对手 × 正反两个站位 = **2400 局**）
先测出基线，发现两个问题：

1. **新角色整体偏弱**：华彩组平均胜率 30%、终曲组 33%，阿特伯格 24 战 **0 胜**。
2. **结构性问题**：`slot 0` 是投掷技的角色，AI 会据此长期保持远距离，
   普通攻击输出被压到接近全场最低（阿特伯格 拳 2.0/s）。而华彩的共鸣恰恰需要"打中"才触发，
   于是这批人既打不到人、也拿不到共鸣。

处理办法（三轮，全部可复现）：

* **结构修正**：把阿特伯格 / 波特凯维茨 / 圣-桑 / 萨列里 的 `Q` 从投掷技改成**四段乐章型乐句**。
  既贴合"交响曲 / 协奏曲作曲家"的设定，也逼 AI 近身。这四人胜率分别
  0% → 21%、33% → 63%、25% → 46%、8% → 67%。
* **数值修正**：按实测胜率对 `DPS` 做最小二乘回归，再把每个越界角色按
  `mult = 1 + (0.5 − 胜率) / (b · DPS)` 缩放其**全部伤害字段**（`damage` / `dps` / `backDamage` / `canon.ratio`），
  倍率夹在 `[0.88, 1.35]` 内，胜率落在 50%±13% 的角色一律不动。
  **回血 / 护盾 / 吸血一律不缩放**——v5.1 已经证明动治疗量会直接破坏 `sustain-test` 的不变量。

| 指标 | v6.0 基线 | v5.1（75 人） | **v6.0 收敛后（100 人）** |
| --- | --- | --- | --- |
| 胜率极值人数（≥72% 或 ≤28%） | **43 / 100** | 18 / 75 | **4 / 100** |
| 胜率标准差 | 0.225 | 0.190 | **0.115** |
| 输出 DPS 最高 / 最低 | 2.69× | 2.17× | **2.09×** |
| 全场平均承受 DPS | 9.82 | 9.91 | **9.93** |
| 镜像击杀耗时（中位） | 27.6s | 30.1s | **27.3s** |
| 镜像击杀耗时（平均） | 29.2s | 30.1s | **29.8s** |
| 完整 3v3 整场 | 101.7s | 99.2s | 约 100s |

> 节奏那一行需要说明：本轮为了拉平胜率把偏弱角色的伤害整体抬了一截（前后共 67 人次），
> 平均承受 DPS 一度涨到 **10.96**、镜像击杀耗时掉回 **27.1s**，把 v5.1 特意放慢的节奏吃掉了一部分。
> 因此把全局乘区 `DAMAGE_SCALE` 从 **0.56 降到 0.51** 做统一补偿——统一乘区对"相对强弱"的影响
> 远小于它对节奏的影响。最终 **9.93 / 29.8s**，与 v5.1 的 9.91 / 30.1s 基本重合。

**仍然存在的问题（如实汇报）**：

* 收敛后仍在极值区的是 **布鲁克纳 88%**（346→334 生命 + 跟随自身的减伤领域，
  改血与减伤后从 100% 降到 88%，仍是全场最高）、**理查·施特劳斯 79%**、**巴托克 79%**、
  **尼尔森 79%**。垫底一档是 阿连斯基 / 萨蒂 / H.普赛尔 29%、马斯奈 33%（都在 28% 线之上）。
* **体系之间仍有系统性差距**，而且纯靠改角色数值修不动：
  **领域**的期望收益最高（移速 +30% 常驻、再加每 8 秒的 ×1.6 爆发），实测平均胜率 **61%**；
  **回旋**最低（**43%**）——它的"免疫 8% + 每 7 秒一次反弹盾"在 AI 对战里收益偏小，
  因为 AI 的普攻节奏本来就慢。中间八套挤在 49%~57%。
  这是 v4.2 时代定下的体系数值，**不在本轮需求的改动清单里**，因此没有擅自调整。
* **测量口径的局限**：矩阵用的是"12 位固定对手"（按生命上限均匀抽样），
  所以胜率里混着一部分"恰好克制这 12 人"的成分，不是纯粹的绝对强度。
  这也是收敛到标准差 0.115 就停手、没有继续压到更低的原因——再压就是在拟合这个对手池的噪声。
* 镜像单挑里 **勃拉姆斯与西贝柳斯**打到 60 秒上限仍未分出胜负（双方都是高血 + 弹道型技能，
  互射效率低）。这与 v5.1 相同，不属于本轮引入的问题。

| # | bug | 影响 | 修复 |

### v5.1（本次）数值平衡 · 75 人外观重构 · 终极技失效修复

#### 一、放慢对局节奏：最大生命 ×10/7

需求给了两条路（「伤害再降 30%」或「抬高最大生命」）。**两条路在数学上是同一个变换**，
但实现代价完全不同，因此选了后者，并把伤害下调叠加上去：

| 方案 | 击杀耗时 | 备注 |
| --- | --- | --- |
| 伤害 ×0.7 | `H / (0.7D − 0.7R)` = **1.43 × H/(D−R)** | 需要改动 381 个伤害数值，且小数值会被取整吃掉 |
| **最大生命 ×1.43** | `1.43H / (D − R)` = **1.43 × H/(D−R)** | **只改 75 个 HP 数值，伤害的整数精度完全保留** |

* 全体最大生命 **190~242 → 271~346**（平均值 204.8 → 292.7），选人界面的体力条分母改为
  由数据实时推导（`HP_BAR_MAX`），不会再出现"改了血上限就全员满格"。
* 伤害再按需求下调 30%：全局系数 `DAMAGE_SCALE` **0.8 → 0.56**。

**v5.1 之后的全局系数（以本节为准，下方各版更新日志里的旧值仅作历史记录）**：

| 常量 | 位置 | v5.1 值 | 含义 |
| --- | --- | --- | --- |
| `DAMAGE_SCALE` | `game.js` | **0.56** | 所有伤害的统一乘区（v2.x 引入时为 0.8） |
| `FIELD_DAMAGE_SCALE` | `game.js` | **0.62** | 领域每跳伤害的额外乘区（v2.1 引入时为 0.8） |
| `HP_BAR_MAX` | `game.js` | 由数据推导（**346**） | 选人界面体力条的归一化分母 |
| 最大生命 | `characters.js` | **271 ~ 346** | 每人 `stats.hp`，平均值 292.7 |
| 回血 / 护盾 | `characters.js` | **保持 v5.0 原值** | 见下方"关于回血要不要跟着升" |

**关于"回血要不要跟着升"**：需求原文在方案 2 里提到"部分有关的技能数值也要升高（如回血）"。
实际算下来**不能升**——把回血也 ×1.43 会让治疗型角色反向变强：
拉赫玛尼诺夫（护盾 31 / 冷却 4s = 7.75/s）面对 12/s 的参考压力只剩 4.25/s 净掉血，
336 血要打 **79 秒**（v5.0 是 36 秒），直接违反项目自带 `sustain-test` 的
"没有人能长期顶住挨打压力"不变量。所以回血 / 护盾 / 吸血比率一律**保持 v5.0 原值**：
这样"伤害"和"治疗"相对血上限同步下降 30%，节奏变化才是均匀的
（等价于方案 1 里把伤害与回血一起 ×0.7）。

#### 三、修掉的 bug（含两个 v5.0 遗留的高危缺陷）

**1）终极技载荷静默丢失 —— 50 / 75 个终极技受影响（最严重）**

`useSkill` 的兜底分支只处理 `field` / `echo` 两种载荷，从不读 `canon` / `movement` / `rondo`：

| 后果 | 数量 |
| --- | --- |
| 只带 `movement` 载荷的终极技**放完什么都不发生** | **10 个**（柴可夫斯基、门德尔松、肖邦、舒伯特、格什温、格里格、斯特拉文斯基、陈其钢、布里顿、武满彻） |
| 声明的 6~8 秒卡农重奏窗口被丢弃 | 34 个 |
| 回旋弹道没有生成 | 6 个 |

现在兜底分支会挂载全部五种载荷，并按载荷选择施法动作。新增 `tools/ultimate-test.mjs`
逐个释放 75 个终极技并断言"至少产生一种实际效果"，以及"数据里声明的每种载荷都在运行时生效"。

**2）地区共鸣的成对判定算错：波兰与比利时被判为互相共鸣**

`regionResonates` 用「第一个包含该标签的集合」求交，而**求交等价于传递闭包**——
法派同时在 `{波兰,法派}` 与 `{比利时,法派}` 里，于是选人界面把伊萨伊高亮成"可共鸣"、
资料面板显示"地区 2 人"，开战后 `computeBonds` 却返回 `null`，黄羁绊根本不生效。
v5.0 的注释已经写明"波兰与比利时之间毫无关系"，是判定函数自己写错了。
现在改成「存在某个候选集合同时包含 a 与 b」+ 同名自反，与 `computeBonds` 完全一致。

**3）硬直只是把已出手的招"冻住"，硬直结束才补刀**

`stepFighter` 的 `disabled` 分支冻结了 `pendingHit` / `multi` / `dash`，于是被打断的技能会在
硬直结束的那一刻才落地——实测贝多芬 W 的判定帧从第 7 帧被推迟到**第 31 帧**，看起来像隔空补刀。
现在受击时直接清掉这三个计时器（格挡姿态除外），被打断就是真被打断。

**4）AI 的技能释放门限与它自己的站位逻辑冲突**

* 弹道技能要求 `d > 150`，但 AI 自己的决策是 `d > 78` 就贴近、只在 `d < keepDist − 50` 才后撤，
  稳态距离被压在 80~140 ⇒ **16 位角色的投掷技在就绪时间里只有 0~4% 满足门限**（西贝柳斯 0%）。
  门槛下调到 `d > 96`。
* 近战技能放行到 `d < 140`，但判定是在出招后第 7 帧才结算、双方都还在移动，
  真正可达只有 ~82~103px ⇒ **30~70% 的释放落在判定框外空转**（肖斯塔科维奇 Q 68%）。
  改为按技能自己的判定框宽度计算：`d < hit.w / 2 + 18`。

**5）AI 终极技多了一道 `G.t < 120` 门槛**：`G.t` 每回合都被 `nextRound()` 清零，
它的语义是"本回合开始后 2 秒"，与 `playT` 的"交战开始后 0.5 秒"重复且更严，
导致第 2 / 3 回合 AI 要多等约 1.8 秒才可能放大招。开局保护统一交给 `playT`。

**6）选人界面体力条分母写死 250**：抬血后 75 人 HP 全部 > 250，体力条**恒为满格**，
属性对比功能完全失效。改为 `HP_BAR_MAX` 由数据推导。

**7）对战音效开关**：`setSfxEnabled` / `setMuted` 原本是瞬时 `setValueAtTime`（硬切，
关闭瞬间正在响的打击音会"咔哒"），改用 20ms 斜坡；`init()` 会把 `sfxGain` 增益写回 0.42
而与 `sfxOn === false` 不一致，现在会沿用当前开关状态；关闭音效时的确认音改到 `toggleSfx()`
**之前**触发，否则"关"这一下会被自己静音、听不到反馈。

**8）其它**：`tickAcc` 未在 `resetRoundState()` 清零（跨回合残留 ±1 帧动画相位）；
设置界面同一帧既按方向键又按确认会 toggle 两次（净效果为不变）；技能描述与实际数值不符
（拉赫玛尼诺夫"吸收 22 点"实际 31、斯克里亚宾"伤害的 40%"实际 57%——两者都是本次抬血/下调
后回退到原值，描述也同步改回）；`drawVs` 空队伍无守卫；死代码 `regionGroupKey` 移除。

#### 四、数值平衡自查（`tools/balance-test.mjs`）

为了能"边改边量"，新写了 `tools/balance-test.mjs`：纯 Node 里搭一个无渲染的对局环境，
**双方都由 `AIController` 驱动**（左边的 AI 通过接管 `readPlayerInput` 接入），可以跑
「同角色镜像单挑」「完整 3v3 整场」「75 人强度矩阵」三类测量，并把伤害按
**拳脚 / 技能直击 / 领域 / 卡农重奏**分桶。测量用固定随机种子，结果可复现。

**第一轮测量就暴露了两个问题**：

1. **测量环境本身是坏的**——`Game.prototype.update` 才会推进 `this.t`，而对局循环只调了
   `updateFight()`，于是 `t` 恒为 0。后果是 `ai.js` 的开局保护 `G.t < 120` 永远成立
   （**AI 一次终极技都不会放**）、`stepCanon` 的 `this.t < c.at` 永远成立
   （**卡农重奏永不结算**）。第一版测出来的"卡农技能 DPS 接近 0"其实是桩的锅。
2. **强度几乎完全由"实际输出 DPS"决定**：胜率与 DPS 的相关系数 **0.92**，
   而 DPS 又几乎由"有没有伤害型领域"决定——拥有领域的角色领域伤害占比高达 56%~72%，
   没有领域的角色这一项是 0。

于是分三轮收敛（每轮都重新测量）：

| 轮次 | 措施 |
| --- | --- |
| 1 | `FIELD_DAMAGE_SCALE` 0.8 → 0.62（只削领域，不动没有领域的角色）；给 7 个"纯放大器"卡农技能（拉莫/布列兹/帕格尼尼/帕赫贝尔/阿连斯基/霍尔斯特 Q、里姆斯基 W）补一个"主题呈示"直击；胜率 ≤29% 的角色直击伤害 ×1.10~1.50 |
| 2 | 弱侧（≤30%）直击 ×1.05~1.30 **并加宽判定框 ×1.06~1.14**（诊断显示弱侧主要是"技能落在框外"，只加伤害没用）；强侧（≥76%）直击 ×0.87、领域 dps ×0.88 |
| — | 另修掉 AI 的两个释放门限（见上"三、bug 4"），这是弱侧空转的另一半原因 |

### v4.2.1 续航数值回调

v4.2 把全体伤害下调了 20%，但**回复类数值没有同步调整**，于是「回血速度 ≥ 挨打速度」
的构筑出现了：只要站在自己的回血领域里，掉血还没有回血快。本次对所有回复类数值做了一轮
体检与回调，并加了自动化的数值护栏。

**体检方法**（`tools/sustain-test.mjs`，可随时复跑）

1. 静态统计每位作曲家所有回复来源的**平均每秒回血**与**峰值回血速率**；
2. 统计**护盾生成速率**（护盾值 / 冷却）与**持续减伤平均幅度**（减伤比例 × 生效占比）；
3. 固定压力实跑：让角色在 **12 点/秒**（实测对局中每方对单一目标的输出水平）的持续挨打下
   把技能一好就放，统计 20 秒里**真实掉血量**。

**回调标准**：平均回血 ≤ 6 点/秒、峰值 ≤ 8.5 点/秒、护盾速率 ≤ 5.5 点/秒、
持续减伤 ≤ 25%，并且**在 12 点/秒 的持续挨打下至少要掉 50% 的伤害量**。

### v4.2

**一、黄色（地区）共鸣：固定 12 秒 → 随机 6~15 秒**

* 原先每 12 秒必定免疫一次，现在每次触发后重新掷点，**下一次在 6~15 秒之间随机**
  （`BOND.regionMin = 360` / `regionMax = 900` 帧），免疫时长仍为 **2.5 秒**。
* 开局不再固定，第一次免疫同样在 6~15 秒之间随机到来；界面徽标改为显示
  `每6~15秒免疫2.5秒` 与实时倒计时。

**二、开局终极技 6 秒初始冷却**

* **每一回合**正式开打（FIGHT 之后）的瞬间，**双方终极技都挂上 6 秒（360 帧）初始冷却**；
  开场 3-2-1 倒计时不计入这 6 秒。轮换上场的新角色同样享有这 6 秒缓冲。
* 实现上冷却在“开打第一帧结算完之后”才挂载，避免同帧被冷却递减吃掉 1 帧，正好锁满 6 秒。
* 实测：AI 首个大招最早出现在交战第 **363 帧**（6.05 秒），50 位角色无一例外；
  玩家在冷却期间按 `E` 也不会放出技能。

**三、跳跃高度提高（最高点刚好能躲开投掷类技能）**

* 跳跃不再用经验公式，而是**按“目标最高点”反推初速度**：离散积分
  （每帧先 `vy += g` 再 `y += vy`）的真实顶点是 `h = v²/(2g) - v/2`，
  反解得 `v = (g + √(g² + 8gh)) / 2`，跳跃高度因此可以被精确控制。
* 最高点由 **约 76px 提高到约 138~143px**（速度最低的角色 138px，最快的约 143px），
  滞空由 32 帧变为 43 帧（0.72 秒）。
* 数值是实测标定的（`tools/combat-test.mjs` 第 11 节，用速度最低的角色做最坏情况）：
  **130px 时 15 个投掷技里有 2 个怎么跳都躲不开，138px 时全部可躲**。取 150px 虽然更宽松，
  但会连多段技能的垂直判定（上限 150px）一起躲掉，所以停在 138px —— 只影响投掷物，
  不改变近战与技能的既有判定。
* 实测每个投掷技的“起跳时机窗口”（提前/推迟多少帧起跳仍能完全躲开）：
  贝多芬 Q **0 帧 → 9 帧**、H.普赛尔 W 12 帧、拉莫 W 12 帧、卡普斯汀 W 12 帧、
  李斯特 W 8 帧、勋伯格 Q 4 帧…… **13/15 个投掷技有 ≥4 帧的操作余量，且没有一个是“怎么跳都躲不开”的**；
  v4.1 的高度在贝多芬 Q 上是 0 帧（完全躲不开）。
* 落地时如果弹体还在（回旋折返、连发弹幕），照样会命中 —— 跳跃只是**时机性闪避**，不是无敌。

### 跳跃（`I`，v4.2）

* 最高点由 76px 提高到 **138~143px**，滞空约 **0.72 秒**；
  **在最高点可以躲开对手的投掷类技能**（如贝多芬的 `Q`）。
* 这是**时机性闪避**：起跳太早或太晚都会被命中；落地时若弹体还在（回旋折返、连发弹幕），
  照样会受伤。三向扇形弹幕覆盖多个高度，跳不过去，请用格挡或后撤应对。
* 实测起跳时机窗口：贝多芬 `Q` 9 帧、H.普赛尔 `W` 12 帧、拉莫 `W` 12 帧……
  15 个投掷技全部都能跳过，其中 13 个留有 ≥4 帧的操作余量。

### 格挡规则（按住 `S`）

* 按住期间角色保持**专门的戒备动画**（双臂交叉护住身前 + 蓝色光罩脉动），被击中时播放
  “被震退再撑回来”的受击帧。即使被打进硬直，只要还按着格挡键，格挡姿态就持续保持。
* **普通攻击**：**75% 概率完全免疫**（0 伤害、无硬直），另外 25% 照常吃满伤害。
* **技能伤害**：**60% 概率随机减免原本伤害的 20%~40%**，另外 40% 无减免。
* 无论概率结果如何，格挡都会把击退降到 60%、硬直减半。
* 标注“无视格挡”的技能（穿透 / 全屏类终极技）不受以上规则影响。

## 赛制规则

1. 开局先**选择三名出场作曲家**（用 `IJKL` 移动光标，`A`/`D` 选中或取消，`P` 清空）。
   敌方三名由系统随机匹配（不重复）。
2. 双方按顺序各上一名角色对战。
3. 一方角色战败 → 该方换上下一名，**战胜方继续留在场上，并保留本轮结束时的血量**。
4. 某一方三名角色全部战败即分胜负，**每局最多 5 轮**。
5. 每轮限时 60 秒；超时后按剩余血量百分比判定该轮胜负。

## 十套战斗体系

> 红色「体系」羁绊标签正是按这里的十套机制划分的
> （和声 / 领域 / 乐章 / 回旋 / 卡农 / 循环 / 节拍 / 华彩 / 终曲 / 顽固），详见上文「羁绊共鸣」。
> 其中 **华彩 / 终曲 / 顽固**是 v6.0 新增的三套**共鸣机制**——它们不像前七套那样对应具体的技能载荷类型，
> 而是直接改对局的规则（眩晕 / 斩杀 / 抗打断），因此没有独立的技能形态。
> 但它们仍然需要**参与共鸣才能触发**（同一体系标签 2 人以上），触发条件与其余七套完全一致。

**v2.0 的两套**（原有 25 位角色的技能机制自 v2.0 起未再改动，v2.1 仅下调了领域伤害）：

### 一、领域（Field）

在战场上留下**持续数秒的音之领域**，是站位与走位层面的压制手段。

* 领域按半径覆盖地面，画面上表现为带旋转符文、上升光柱与脉冲边界的魔法阵；
* 类型包括：**持续伤害**、**减速**、**治疗自身**、**护甲减伤**、**吸血**，以及拉威尔专属的**渐强**；
* 分为**跟随施法者**与**落在对手脚下**两种投放方式；同一施法者的同类领域只保留最新一个；
* **领域伤害在 v2.1 统一下调 20%**（`FIELD_DAMAGE_SCALE`），减速也没有 0.5 的下限，
  保证被压制的一方仍有机会脱身或反击；
* AI 会主动走出对手的**伤害型**领域——但逃太久它会回身硬拼，不会无限风筝。

### 二、回声（Echo）

召出**作曲家的半透明虚影**（残影会真实挥拳／踢腿），从不同方位与不同时刻发动攻击。

* 虚影按指定方位（对手身前／身后／两侧）与延迟依次现身，脚下有魔法阵；
* 出生与命中都有专门的粒子表现；虚影攻击遵循技能的全部判定与格挡规则；
* 因为落点是“对手的当前位置”，走位可以躲开，但背后突袭极难反应——
  例如海顿「惊愕交响曲」就是**从对手背后突然现身的一记重击**。

**v3.0 新增的三套**（25 位新角色）：

### 三、乐章（Movement）

技能展开一段**多段式乐句**，按拍点**自动连续发动不同招式**（每段的伤害、范围、硬直各不相同）。

* 施法者头顶会浮出**五线谱指示器**，用音符点标出还有几拍未奏；
* **连奏期间施法者不被招式动画锁定**（`freeMove`），仍可自由走位、跳跃、格挡甚至另起一招——
  这是与“多段连击”最本质的区别；
* 每到一个拍点都会自动判定命中，玩家只需专注走位；
* 代表技能：柴可夫斯基「天鹅湖·四小天鹅之舞」（四段踢击）、
  格里格「在山魔王的宫殿里」（四段伤害逐段攀升）、
  斯特拉文斯基「春之祭」（间隔忽长忽短的四段重音）、
  伯恩斯坦「坎迪德序曲」（四段急板）等。

### 四、回旋（Rondo）

放出的乐句**飞到尽头会折返**，去程与回程**各判定一次**。

* 回程的伤害通常**高于去程**（面板上 `damage` / `backDamage` 分开标注）；
* **回程命中会把对手向施法者方向拖拽**（`pull`），可以把逃跑的对手硬拽回来；
* 乐句回到施法者手中后消失，飞行途中带方向指示与尾迹特效；
* 代表技能：柏辽兹「幻想交响曲·固定乐思」（那条挥之不去的旋律）、
  乔普林「枫叶拉格」（切分的乐句弹出去又跳回来）、
  H.普赛尔「狄多与埃涅阿斯·狄多的哀歌」等。

### 五、卡农（Canon）

开启后的一段时间内，自己的**每一次命中都会被一个延后的“模仿声部”重奏一次**。

* 重奏伤害 =（该次命中伤害 × 面板比例），在设定的延迟帧后自动结算；
* 重奏时对手身上会浮现**虚影挥击 + 音符爆散**，自身头顶有音符环与剩余时间读数；
* 卡农是**自我强化**：持续期间打得越密，追加伤害越多；
  适合先手开启、再以多段技能或乐章扩大收益；
* 代表技能：帕格尼尼「二十四首随想曲」（比例 0.6）、
  布列兹「应答曲」（0.85，最高倍率）、
  韦伯「魔弹射手·魔弹」（同一颗子弹再打一次）、
  马肖「等节奏经文歌」（严格重复）等。

### 六、循环（Loop）（v5.0 新增）

**同一音型反复回响**——这是 12 位新角色共有的性格，具体落地为三种"会重复自己"的表现：

* **固定低音**：一条低音走到底，上面的声部一轮轮追上来（帕赫贝尔《D 大调卡农》、
  阿连斯基《固定低音》、弗兰克《d 小调交响曲》的循环主题）；
* **点描碎片**：每个音独立成击，序列被反复陈述
  （韦伯恩《六首小品》《交响曲 Op.21》、梅西安《有限移调模式》）；
* **不可移位的音块 / 逐次累加**：梅西安的音块像钟一样反复敲响、
  J.N.胡梅尔的回旋曲主题一次次回来且每次更花哨。

> **体系共鸣**：参与共鸣的角色**对战时每 7 秒回复 18% 已损失生命**。
> 结算时按**当时的**已损失生命重新计算，所以越回越少：
> 以帕赫贝尔（HP 205）为例，掉到 92 时第一次回 20 点，
> 之后每个周期分别回 18、16 …… 三个周期合计回血 43 点。

### 七、节拍（Beat）（v5.0 新增）

**舞曲式的强拍律动**——13 位新角色以密集而规整的攻击节奏压制对手：

* **均匀连击**：音阶 / 练习曲式的等时值跑动（车尔尼《快速练习曲》、车尔尼《手指灵巧的艺术》）；
* **卡农式追随**：后一声部紧咬前一声部（里姆斯基-科萨科夫《野蜂飞舞》、
  斯美塔那《我的祖国》、布鲁赫《科尔尼德莱》）；
* **五拍子 / 六拍子轮舞**：塔兰泰拉、波尔卡、帕凡（安东·鲁宾斯坦、斯美塔那、福莱）；
* **急速回旋**：序曲的急速音型冲出去又冲回来（格林卡《鲁斯兰与柳德米拉》、胡梅尔《回旋曲》）。

> **体系共鸣**：参与共鸣的角色**普通攻击（挥拳和踢腿）的攻击速度 +20%**。
> 实现方式是**动画推进倍率**（`basicSpeed`）：挥拳整段 25 帧 → 21 帧、
> 踢腿 35 帧 → 30 帧，判定帧（挥拳 5~14 / 踢腿 7~18）随之等比缩短但仍充足。
> 该加成只影响拳脚，**不影响移动速度与技能冷却**。

## 一百位作曲家

每人拥有两个技能（`Q` / `W`）与一个终极技能（`E`），技能名称取自其代表作品，效果“望文生义”地对应曲目意境。

**冷却时间按技能机制自适应（v4.0）**：

* **持续型技能**（领域 / 回声 / 乐章 / 回旋 / 卡农 / 护盾 / 增益 / 状态）：
  冷却 = 持续时间 + 余量（普通技能 +2.5 秒，终极技 +5 秒）。
  例如拉威尔「波莱罗舞曲」持续 12 秒 → 冷却 15 秒；8 秒的领域 → 冷却 11 秒。
* **纯伤害型技能**（投射物 / 突进 / 连击 / 无持续时间的终极技）：
  冷却相应放低，普通技能 4 秒、终极技 12 秒。
* 全部 **300** 个技能（100 位 × 3）都满足「冷却 > 持续时间」，不存在效果无限延续的情况。

> 平衡说明：阿特伯格 / 波特凯维茨 / 圣-桑 / 萨列里 原本的 Q 是**投掷技**，
> 而 AI 会据此长期保持远距离、几乎不出普攻（阿特伯格的普攻输出一度是全 100 人最低，
> 24 战 0 胜）。四人的 Q 因此改成**四段乐章型乐句**——既贴合"交响曲 / 协奏曲作曲家"的设定，
> 也逼 AI 近身。改后四人胜率分别 0%→21%、33%→63%、25%→46%、8%→67%。

## 技术实现

```
开始游戏.html        页面与按键说明（双击这个文件启动）
styles.css          街机外壳样式
js/audio.js         8bit 音乐引擎（32 首曲谱 + 3 声部 + 20 种音效 + 15 种鼓型 + 音效开关）
js/characters.js    100 位作曲家的数值、配色、技能与羁绊标签
js/sprites.js       像素角色绘制（骨骼式姿势 + 低帧率关键帧动画）
js/effects.js       像素字体（含小写字母 + 中文自动回退）+ 技能特效粒子系统
js/ai.js            敌方 AI（距离/冷却/性格驱动；会躲伤害领域但不会无限风筝）
js/game.js          对战引擎（十套战斗体系、羁绊、轮换赛制、界面）
js/main.js          固定 60Hz 逻辑主循环
tools/              开发期验证工具（不影响游戏运行）
```

* 逻辑固定 60Hz 步进；**动画每 6~8 帧才切一次关键帧**，还原红白机特有的“卡顿感”。
  （唯一例外是红色「节拍」共鸣：挥拳 / 踢腿的动画按 1.14 倍速推进，
  用浮点累加器折算成整数帧，避免 `tick` 变成小数。）
* 角色为“骨骼式”绘制：大腿/小腿/上臂/前臂的角度数据驱动，因此挥拳、踢腿、
  格挡、格挡受击、**领域施法、回声召唤、乐章挥棒、回旋甩出、卡农倾听**、
  跳跃、受击、胜利姿势都是独立编排的动画。
* **形象差异由三层数据叠加而成**：
  1. **发型库**（`HAIR_STYLES`，**24 种**，前后两层圆角矩形数据驱动）；
  2. **面部特征**（`FACE_MAP`：脸型／眼型／眉型／鼻型／嘴型／腮部阴影）；
  3. **衣着与配饰**（**13 套版型** + **21 种手持物** + **12 种帽子** +
     披风／围巾／绶带／拉夫领 + 眼镜／单片眼镜／烟斗／耳饰／胡须／胸前十字架）。
  三者组合后 100 位作曲家**形象两两不同**，`tools/looksheet.html` 与
  `tools/facesheet.html` 可放大逐一核对。
* 像素风判定：所有角色、特效、文字均用整数像素矩形/圆角矩形绘制，
  `image-rendering: pixelated` 保证放大后仍是硬朗色块。

## 开发者验证工具（可选）
